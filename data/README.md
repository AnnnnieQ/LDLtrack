# Effect Sizes Database

## Sources

### Primary sources for statin effects

1. **Karlson BW et al. 2015** — *Atherosclerosis* 241(2):450-4
   - VOYAGER meta-analysis, 8,496 patients, 37 RCTs
   - Source: Figure 1 (LSM percentage change in LDL-C by statin benefit group)
   - PMID: 26074319 | DOI: 10.1016/j.atherosclerosis.2015.05.029
   - Provides 20 data points: 4 high-intensity statin doses × 5 patient subgroups

2. **2018 ACC/AHA Cholesterol Guideline (Grundy et al.)** — *Circulation*
   - Source: Table 3 "High-, Moderate-, and Low-Intensity Statin Therapy"
   - PMID: 30586774
   - Provides moderate- and low-intensity statin classifications

## Data Quality Notes

- **Standard error estimates**: SEs not directly reported in source figures; estimated as ~1-1.5% based on visible error bars in Karlson 2015 Fig. 1
- **Population labels**: ASCVD = atherosclerotic CV disease patients; LDL_geq_190 = baseline LDL ≥190 mg/dL; etc.
- **Evidence quality**: RCT_meta = direct from RCT meta-analysis; RCT_estimate = derived from guideline classification; FDA_labeling = from drug labeling
